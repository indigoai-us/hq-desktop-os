# HQ Desktop

HQ Desktop helps people set up HQ on their computer, connect their account, and keep their work available across devices. It serves semi-technical and nontechnical people who should not need to understand packages, processes, or cloud infrastructure.

The first successful experience is a guided setup followed by a clear view of the selected workspace and its actual sync state. Existing users can choose their HQ folder without changing its contents. Required software is checked and installed through a resumable setup flow. Optional tools stay optional.

Use everyday language. Keep developer diagnostics out of the main experience, with a private support report in settings. Do not include a documentation link, an editor promotion, runtime names, or build engineering notes in the product UI. Never report setup or sync success without evidence.

Accessibility includes keyboard navigation, visible focus, both color schemes, reduced motion, and reflow at enlarged text. Linux and Windows use one native title bar.
