# HQ Desktop design

## Direction

A calm desktop utility with guided setup, generous breathing room, and familiar HQ branding. The user explicitly requested softer shapes and the current hq-work-mono visual language on September 11, 2026. This supersedes the earlier square control direction for this project.

## Reference translation

| Reference | Desktop OS application |
| --- | --- |
| hq-work-mono onboarding HQ wordmark | The same SVG mark in welcome and navigation |
| Shared neutral V4 materials | Solid neutral sidebar and canvas suitable for Linux and Windows |
| 6px fields and buttons, 8px popovers | Rounded shared control tokens, no nested bordered panels |
| 13/14/15/17/24px type ramp | Readable body, restrained metadata, clear page headings |
| hq-desktop-app setup stages | Guided dependency preparation, workspace setup, account connection, and sync with retry |

Use a darker sidebar than canvas in light mode. Navigation selection uses a background highlight. Reserve color for success, attention, and errors. The theme preference is one native select with System, Light, and Dark options in Settings. Use stroke icons for actions. No decorative cards, accent stripes, custom window buttons, or technical badges.

The welcome screen has one clear next action and a quieter existing-folder choice. Everyday views use open sections separated by space or a hairline. Support details are collapsed by default. All asynchronous actions show a pending state immediately and prevent duplicates. Copy names the user's next step, not the implementation.
